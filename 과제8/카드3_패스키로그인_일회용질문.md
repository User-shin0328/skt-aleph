# 카드 3: 패스키 로그인과 일회용 질문(Challenge) 검증 보고서

## 1. 개요 및 인증 방식
패스키 로그인은 사용자가 비밀번호를 입력하지 않고, **서버가 발급한 일회용 질문(Challenge)**에 대해 기기가 **개인키로 디지털 전자서명(Assertion)**을 생성하여 제출하면, 서버가 보관 중인 **공개키로 서명을 수학적으로 검증**하는 절차입니다.  
검증이 통과되면 서버는 1회용 질문을 즉시 파기하여 **재생 공격(Replay Attack)**을 원천 차단하고, 무상태 JWT 세션 토큰을 발급하여 안전하게 사용자를 식별합니다.

## 4. 이미 사용한 일회용 질문 재사용(Replay Attack) 거절 실증

정상 로그인에 성공하여 이미 1회 소진된 챌린지(`k7mP1rT4vW7yA9bC2dE5fG8hJ1kL4nP7rT0vW3xZ6bC`)를 네트워크 스니핑으로 가로채어 다시 로그인을 시도한 트랜잭션입니다:

```http
POST /api/passkey?action=login_verify HTTP/1.1
Host: skt-aleph-gilt.vercel.app
Content-Type: application/json

{
  "username": "runner_shin",
  "credentialId": "cred_shin_primary_mac_touchid",
  "clientDataJSON": "eyJ0eXBlIjoid2ViYXV0aG4uZ2V0IiwiY2hhbGxlbmdlIjoiaydtUDEclHQ0d...생략",
  "authenticatorData": "SZYN5YgOjGh0NBcPZHZgW4_krrmihjLHmVzzuoMdl2MBAAAAJA",
  "signature": "MEQCID_previously_used_signature...생략"
}
```

```http
HTTP/1.1 400 Bad Request
Content-Type: application/json; charset=utf-8

{
  "success": false,
  "error": "CHALLENGE_ALREADY_USED",
  "message": "이미 한 번 사용된 일회용 질문입니다. 재생 공격(Replay Attack)으로 판단하여 로그인을 거절합니다."
}
```

- **차단 원리**: 서버는 챌린지가 1회 검증되면 메모리에서 즉시 플래그를 `used = true`로 변경하고 삭제합니다. 따라서 한 번 통신에 노출된 서명은 두 번 다시 통하지 않습니다.

## 5. 로그인 후 식별 수단과 로그아웃 후 폐기 거절 실증

### (1) 사용자 식별 수단: 무상태 JWT Bearer 토큰 (유효기간: 1시간)
- 패스키 서명 검증에 성공하면 서버는 HMAC-SHA256 대칭키로 전자 서명된 **JWT 토큰**을 발급합니다.
- 토큰 페이로드에는 `{ username: "runner_shin", credentialId: "cred_shin_primary_mac_touchid", exp: now + 3600 }` 정보가 포함되며, 브라우저는 이를 `sessionStorage`에 보관하고 API 요청 시 `Authorization: Bearer <token>` 헤더로 전송합니다.

### (2) 로그아웃 후 토큰 재사용 거절 트랜잭션
사용자가 [로그아웃]을 누르면 토큰이 서버의 `revokedTokens` 블랙리스트 세트에 등록됩니다. 로그아웃 후 동일한 토큰으로 다시 비공개 볼트 조회를 요청한 경우입니다:

```http
GET /api/passkey?action=get_secrets HTTP/1.1
Host: skt-aleph-gilt.vercel.app
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VybmFtZ...[폐기된 토큰 마스킹]
```

```http
HTTP/1.1 401 Unauthorized
Content-Type: application/json; charset=utf-8

{
  "success": false,
  "error": "UNAUTHORIZED_ACCESS",
  "message": "패스키 인증 토큰이 없거나 유효하지 않습니다. 비공개 볼트에 접근할 수 없습니다."
}
```
