[짧은 확인 방법 4줄]
1. 어디로 가나요: 웹 브라우저에서 https://skt-aleph-gilt.vercel.app 접속 후 상단 공개 영역 박스 바로 아래의 [🔒 비공개 영역 — 핵심 역량과 실증 사례] 섹션으로 이동합니다.
2. 세 단계 안에 무엇을 하나요: [패스키로 로그인] 클릭 -> 기기 생체인증/디지털 서명 승인 -> [패스키 인증 성공] 상태에서 비공개 핵심 역량 3종(계획과 정리, IDS 트러블슈팅, 팀 협업) 및 [근거 증빙 확인] 토글을 확인합니다.
3. 무엇이 보이면 통과인가요: 에메랄드 [🔓 패스키 인증 성공] 뱃지와 함께 STAR 구조의 핵심 역량 3대 카드, 인라인 세부 근거 증빙 토글, 2개의 등록된 기기 목록이 정상 출력됩니다.
4. 안 될 때는 무엇이 보이나요: 로그인 전에는 주황색 [🔒 비공개 잠김 상태]와 잠금 안내만 보이며, 권한 없이 직접 API 호출 시 HTTP 401 Unauthorized 거절 메시지가 표시되고 HTML 소스코드에 핵심 역량 텍스트가 전혀 나오지 않습니다.

[AI와 내 판단 3줄]
1. AI에게 맡긴 일: W3C WebAuthn FIDO2 P-256 ECDSA 디지털 서명 검증 알고리즘 구현, 실시간 콘솔 터미널 UI 마크업 및 핵심 역량 3종 STAR 카드/근거 토글 템플릿 작성을 위임함.
2. 내가 직접 판단한 일: 소개 페이지를 상단 '공개 영역 박스'와 하단 '비공개 영역 박스'로 명확히 양분하고, 패스키의 기기 분실 위험을 해결하기 위해 '다중 패스키 등록 및 1개 삭제 후 잔여 키 로그인' 복구 체계를 필수로 도입함.
3. AI 제안을 따르지 않은 일: AI가 초기에 제안한 타사 상용 WebAuthn SaaS 연동 방식을 거부하고, 어떤 브라우저 환경에서도 즉시 검증할 수 있도록 순수 Node.js crypto 기반의 경량 서버리스 API를 탑재하도록 통제함.
