카드 2

말이 아니라 근거 (STAR & Evidence)

T01-C06 ~ T01-C09

나열식 주장이 아닌, 실제 발생한 상황(Situation), 직접 수행한 행동(Action), 관찰된 결과(Result)와 공개 가능한 실증 근거입니다.

강점 1. 네트워크 패킷 이상 징후 추적 및 프로토콜 디코딩

[상황 Situation]

패킷 트레이서 및 로컬 서버 통신 중 응답 지연이 발생하여, 3-Way Handshake 수립 과정에서 비정상 재전송(Retransmission) 여부를 판별해야 했습니다.

[행동 Action]

Wireshark를 실행하여 TCP 필터(tcp.flags.syn==1)를 적용하고, 시퀀스 번호 교환 및 SYN 패킷의 플래그 변조 여부를 추적했습니다.

[결과 Result]

정상 3단계 핸드셰이크 흐름을 타임스탬프 단위로 검증하고, 지연 구간이 서버 백로그 큐 초과로 인한 문제임을 도출하여 해결책을 확립했습니다.

강점 2. 웹 애플리케이션 취약점 진단 및 시큐어 코딩 대응

[상황 Situation]

사용자 인증 폼에서 입력값 검증이 누락되어 악의적인 인라인 SQL 삽입 공격에 취약한 상태를 식별했습니다.

[행동 Action]

인증 우회 페이로드(' OR '1'='1)를 모의 검증한 후, 동적 문자열 연결 대신 파라미터화된 Prepared Statement 쿼리로 전면 전환했습니다.

[결과 Result]

쿼리 구조와 데이터가 물리적으로 분리되어 비인가 인증 우회를 원천 차단하고 취약점 점검 항목을 100% 통과했습니다.

강점 3. 리눅스 시스템 보안 진단 및 비인가 권한 상승 탐색

[상황 Situation]

다수 계정이 공존하는 리눅스 실습 서버에서 일반 사용자가 관리자 권한을 획득할 수 있는 고위험 SetUID 파일 관리 필요성이 대두되었습니다.

[행동 Action]

find / -perm -4000 정밀 스크립트를 작성하여 시스템 내 4000 권한 바이너리를 자동 전수 추출하고 화이트리스트와 대조했습니다.

[결과 Result]

불필요하게 실행 권한이 부여된 비표준 바이너리를 즉각 격리하고 무결성 유지 절차를 정례화했습니다.

실제 결함 세 개 (수정 전후 기록)

T01-C13 ~ T01-C18

배포 전 진행한 웹 접근성(WCAG AA), 키보드 탐색, 헤딩 단계, 브라우저 콘솔 검사에서 식별된 실제 결함 3가지의 구체적 수정 전후 내역입니다.

결함 항목 (기준) 수정 전 상태 (Before) 수정 후 상태 (After)
결함 1. 텍스트 명암 대비율
T01-C16 (4.5:1 이상)
 다크 배경 대비 본문 텍스트 색상이 옅은 회색(#52525b)으로 지정되어 명암 대비율 3.1:1로 WCAG 일반 텍스트 기준(4.5:1)에 미달함. 일반 본문 텍스트를 고대비 밝은 회색(#f4f4f5 및 #d4d4d8)으로 변경하여 명암 대비율 9.2:1을 확보하여 완벽 가독성 달성.
결함 2. 제목 태그 단계 건너뜀
T01-C15 (계층 구조)
 메인 타이틀 <h1> 직후에 카드 내부 소제목이 <h4>로 직접 건너뛰어 스크린 리더 제목 탐색 트리가 단절되는 결함 발생. 페이지 최상단 <h1> → 각 카드 대제목 <h2> → 세부 항목 <h3>으로 단계적 계층 구조를 엄격히 재배치.
결함 3. 키보드 Tab 초점 미표시
T01-C14 (Tab 이동)
 기본 outline: none 설정으로 인해 Tab 키로 이동 시 현재 어디에 초점이 위치하는지 시각적 표시가 전혀 나타나지 않음. 모든 대화형 요소에 focus-visible:outline-2 outline-brown-400 및 건너뛰기 링크(Skip Navigation)를 신설하여 키보드만으로 순차 탐색 보장.
