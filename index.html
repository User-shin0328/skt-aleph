비밀번호 입력란은 존재하지 않습니다. 등록된 기기의 패스키 서명으로 나만의 비공개 자리를 안전하게 엽니다. (기기 분실 대비 새 패스키 추가는 로그인 후 관리 패널에서 본인 인증을 거쳐 진행됩니다.)

📱 기기 분실 대비 다중 패스키 관리 목록 2개 등록됨

* 기기를 잃어버렸을 때를 대비해 패스키를 2개 등록해 두고, 하나를 삭제한 뒤에도 남은 하나로 들어갈 수 있습니다.

패스키 이름 인증기 유형 / 보안 저장소 등록일시 (KST) 서명 횟수 분실 관리
🗝️ 서버 보관 데이터 증적: 비밀번호 0건 & 오직 비대칭 공개키(Public Key)만 저장
과제 8 카드 2 핵심 실증

패스키 시스템은 서버에 비밀번호나 개인키를 절대 보관하지 않습니다. 서버 데이터베이스에는 누구나 보아도 안전한 NIST P-256 타원곡선 공개키(x, y 좌표)만 저장되며, 서명을 찍는 개인키(Private Key)는 내 기기 보안 칩 내부를 절대 벗어나지 않습니다.

🔄 일회용 질문(Challenge) & 재생 공격(Replay Attack) 방어 실시간 검증
과제 8 카드 3 핵심 실증

패스키는 비밀번호를 일체 전송하지 않으며, 서버가 매번 새롭게 던지는 일회용 질문(32B Challenge)에 기기의 개인키로 서명하여 인증합니다.
서버는 서명을 확인하는 즉시 질문을 영구 파기하므로, 해커가 통신 패킷을 도청·복제하여 똑같이 보내더라도(재생 공격) 즉시 400으로 차단됩니다.

1️⃣ 매번 새로운 질문 발급 비교

서버에 연속 2회 질문(Challenge)을 요청하여 32바이트 난수 질문이 매번 100% 달라지는지 실시간 확인합니다.

위 [⚡ 새 질문 2회 연속 요청] 버튼을 누르면 실시간 비교 결과가 표시됩니다.
2️⃣ 이미 쓴 질문 재사용(도청 복제) 차단

이미 정상 로그인에 소모된 질문을 가로채어 다시 보냈을 때 서버가 즉시 400 거절하는지 확인합니다.

위 [🛡️ 재생 공격 차단 시험] 버튼을 누르면 실시간 방어 결과가 표시됩니다.

새 기기(휴대폰 등) 패스키 발급

현재 인가된 이 컴퓨터에서 승인 코드를 발급해야만 다른 기기(스마트폰 등)에서 패스키를 등록하고 비공개 구역에 들어갈 수 있습니다.

보조 기기 등록용 1회용 승인 코드 (10분 유효)
------
📱 휴대폰 등 다른 기기 등록 방법:
1. 등록할 기기로 본 사이트에 접속합니다.
2. 비공개 영역 하단의 [마스터 컴퓨터에서 발급받은 코드로 등록] 클릭
3. 위의 6자리 코드를 입력하면 해당 기기에 패스키가 발급됩니다.
DEVICE PASSKEY CLAIM

이 기기(휴대폰) 패스키 등록

마스터 컴퓨터 화면에 표시된 6자리 승인 코드를 입력하여 이 기기에 정식 패스키를 발급·등록합니다. (마스터 컴퓨터에서 승인하지 않은 기기는 등록 불가)

✓ 기기 인가 보안 원칙:
- 마스터 컴퓨터의 사전 승인 없이는 패스키 발급 불가
- 등록 완료 시 이 기기 로컬에 고유 패스키가 안전 저장됨
