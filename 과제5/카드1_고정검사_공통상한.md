### 3. 작업 전 고정 검사 10개 명세 (T05-C01 ~ T05-C04)

| 검사 ID (T05-C02) | 검사 목적 | 구체적 입력 (T05-C03) | 관찰 가능한 기대값 (T05-C04) |
|:---|:---|:---|:---|
| **T05-TEST-01** | 기본 UI 렌더링 검사 | 페이지 로드 (`DOMContentLoaded`) | `#fxCalculatorSection` 내 입력창 및 USD/JPY/CNY 결과 카드가 정상 노출된다. |
| **T05-TEST-02** | USD 환산 정확도 검증 | 원화 `1,000,000` 입력 | `1,000,000 / USD환율` 수식 적용 결과가 소수점 2자리로 `#calcResultUsd`에 출력된다. |
| **T05-TEST-03** | JPY (100엔 공식) 환산 정확도 검증 | 원화 `100,000` 입력 | `(100,000 / JPY_100) * 100` 수식 적용 결과가 소수점 2자리로 `#calcResultJpy`에 출력된다. |
| **T05-TEST-04** | CNY 환산 정확도 검증 | 원화 `100,000` 입력 | `100,000 / CNY환율` 수식 적용 결과가 소수점 2자리로 `#calcResultCny`에 출력된다. |
| **T05-TEST-05** | 빠른 금액 버튼 동작 검증 | `[100만]` 버튼 클릭 | 입력창에 `1,000,000`이 자동 주입되고 환산 결과가 즉시 동기화되어 갱신된다. |
| **T05-TEST-06** | 0원 입력 안전성 검증 (Zero-value) | 금액 `0` 입력 | 결과 필드에 `0.00`이 안전하게 표시되고 `NaN`이나 오류가 발생하지 않는다. |
| **T05-TEST-07** | 음수 입력 차단 검증 | 금액 `-50000` 입력 | `#calcInputValidMsg`에 '금액은 0보다 커야 합니다.' 경고가 출력되고 계산이 차단된다. |
| **T05-TEST-08** | 문자열/특수문자 입력 방어 검증 | `abc#$%` 입력 | `#calcInputValidMsg`에 '유효한 숫자를 입력해주세요.' 경고가 출력되고 계산이 차단된다. |
| **T05-TEST-09** | 초기화 버튼 기능 검증 | `[초기화]` 버튼 클릭 | 입력창이 `0`으로 리셋되고 모든 통화 환산 결과가 `0.00`으로 안전하게 초기화된다. |
| **T05-TEST-10** | 오프라인/캐시 환율 연동 검증 | 네트워크 단절 상태에서 `50,000` 입력 | `localStorage`에 캐시된 마지막 정상 환율을 읽어와 중단 없이 정상 계산을 수행한다. |
