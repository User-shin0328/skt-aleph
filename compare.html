대화가 끊겨도 이어지는 프로젝트

과제 4의 실시간 환율 계산기 기능을 두 AI 세션이 차례로 이어서 완성하였습니다. 첫 번째 AI의 대화 전문 없이, 저장소와 7칸 인수인계 문서(HANDOFF.md)만으로 두 번째 AI가 작업을 완벽히 재개하여 10개 검사를 모두 통과시킨 실증 보고서입니다.

1. 순차 진행 타임라인 (T05-C07)

AI A 시작 → AI A 종료·인수인계 → AI B 시작 → AI B 완료 순서를 엄격히 준수하여 기록되었습니다.

STAGE 1 · 사전 검사 및 상한선 고정 (T05-C01 ~ T05-C06)
작업 착수 전 고정 검사 10개 및 공통 상한 확정
과제 4 '실시간 환율 변환 계산기'를 개선 대상으로 선정하고, ID/입력/기대값이 명시된 고정 검사 10개 확정. 공통 사용 상한: 시간 60분, 호출 수 15회 설정.
STAGE 2 · AI A 작업 및 중단 (T05-C08, T05-C09)
도구 A 스캐폴딩 및 5개 검사 통과 후 세션 중단
기본 계산기 UI 마크업 및 원화→외화 계산 수식 구현(TEST-01~05 통과). 계획된 시점에서 작업을 멈추고 버전 커밋 생성 및 7칸 인수인계서(HANDOFF.md) 작성.
STAGE 3 · AI B 인계 및 작업 재개 (T05-C13, T05-C14)
대화 전문 없이 저장소와 인수인계 문서만으로 착수
새 세션에서 AI A의 대화 로그 일체 없이 HANDOFF.md와 Git 버전만을 수신하여 작업 착수. 누락 검토 결과 7항목 완벽 재현 확인.
STAGE 4 · AI B 기능 완성 및 10개 검사 완주 (T05-C16 ~ T05-C20)
남은 결함 5개 전원 해결 및 10/10 PASS 달성
0원 처리, 음수 입력 경고, 문자 차단, 빠른 금액 프리셋 버튼, 오프라인 캐시 계산을 완성하여 10개 고정 검사 100% 통과 완료.

4. 7칸 인수인계 문서 전문 (T05-C10)

AI A가 작업 중단 시 남긴 실제 인수인계서(HANDOFF.md) 원문입니다.

HANDOFF.md
================================================================================ 7칸 인수인계 문서 (HANDOFF.md) 버전 ID: 452eb2a1d29fa756306c4b22c7eb1df0b89b889b ================================================================================ 1. 목표 (Goal) 과제 4(board.html) 환율 카드 하단에 실시간 환율 변환 계산기 기능을 구현하여, 고정 검사 10개(T05-TEST-01 ~ T05-TEST-10)를 100% 통과시키는 것. 2. 현재 상태 (Current State) 계산기 기본 UI(#fxCalculatorSection) 및 원화->외화 기본 계산식 calculateExchange() 스캐폴딩 완료. 기본 10만 원 입력 시 USD/JPY/CNY 정상 계산 작동 중. 3. 실행 명령 (Execution Commands) - 코드 확인: board.html - 라이브 확인: http://localhost:3000/board.html 또는 https://skt-aleph-gilt.vercel.app/board 4. 통과 검사 (Passed Tests) - T05-TEST-01: 기본 UI 렌더링 (PASS) - T05-TEST-02: 100만 원 입력 시 USD 환산 정확도 (PASS) - T05-TEST-03: 10만 원 입력 시 JPY (100엔 공식) 환산 정확도 (PASS) - T05-TEST-04: 10만 원 입력 시 CNY 환산 정확도 (PASS) - T05-TEST-05: 빠른 금액 100만 버튼 입력 및 자동 계산 (PASS) 5. 남은 문제 (Remaining Issues) - T05-TEST-06: 0원 입력 시 예외 처리 누락 (NaN 또는 빈칸 발생) - T05-TEST-07: 음수(-50,000) 입력 시 경고 메시지 없이 음수 계산 출력됨 - T05-TEST-08: 문자열('abc') 입력 시 NaN 발생 및 안내 메시지 부재 - T05-TEST-09: 초기화 버튼 클릭 시 0.00으로 리셋하는 resetCalculator() 미구현 - T05-TEST-10: 네트워크 오프라인 시 localStorage 캐시 환율 자동 폴백 로직 미비 6. 다음 행동 (Next Action) calculateExchange() 함수 내에 입력값 유효성 검사(0, 음수, 문자열)를 추가하고, resetCalculator() 구현 및 currentFxRecord 미로드 시 localStorage 캐시 읽기 로직을 연결할 것. 7. 건드리지 말 것 (Scope Restrictions) - 기존 서울 실시간 기온 카드(#board-metric-card) 및 일별 기록 테이블(#liveDailyTableBody) 구조 변경 금지 - Open-Meteo 및 open.er-api.com 통신 인터페이스 및 비밀키 0건 원칙 엄수 ================================================================================
