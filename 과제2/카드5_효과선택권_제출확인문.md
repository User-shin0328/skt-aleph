# [과제 2 / 카드 5] 효과와 선택권

## 남길 것: 효과 사건·끄기 선택·비밀값 점검 & 제출 확인문

---

### 1. 시청각 효과 발생 사건 (T02-C26)
- **점프 사건**: Web Audio API 기반 순수 합성 효과음(바람소리/도약음) 재생
- **충돌 사건**: 장애물 접촉 시 화면 흔들림(Screen Shake) 효과 및 충돌음 발생
- **완주 성공 사건**: 30초 완주 시 보안관 배지 팡파르 화음 재생

---

### 2. 접근성 끄기 선택권 (T02-C27)
- **[음소거(Mute)] 토글**: Web Audio API Master Gain 노드를 0으로 뮤트하여 사운드 즉시 정지
- **[움직임 줄이기(Reduce Motion)] 토글**: 화면 흔들림(Screen Shake) 효과 즉각 비활성화

---

### 3. 보안 및 비밀값 점검 (T02-C28, T02-C29)
- 공개 화면 및 소스코드 내 개인정보 노출: **0건**
- 비밀번호, 비공개 토큰, API 키 원문 노출: **0건**

### 4. 짧은 확인 방법 4단계 (T02-C30)
1. **어디로 가나요**: [https://skt-aleph-gilt.vercel.app/game.html](https://skt-aleph-gilt.vercel.app/game.html)
2. **3단계 이내 무엇을 하나요**:
   - Step 1: Space 키를 눌러 게임을 시작하고 점프합니다.
   - Step 2: 상단의 [음소거] 또는 [움직임 줄이기]를 클릭합니다.
   - Step 3: 30초 동안 완주하거나 장애물에 충돌한 뒤 'R' 키로 재시작합니다.
3. **무엇이 보이면 통과인가요**: 캐릭터가 장애물을 피해 점프하고, 효과 끄기 시 화면 흔들림/소리가 즉시 정지하며, 성공/실패 후 상태가 완전 초기화되면 통과입니다.
4. **안 될 때 무엇이 보이나요**: 키보드 점프가 반응하지 않거나, 화면이 멈추거나, 콘솔에 빨간 오류가 출력되는 상태입니다.

### 5. AI 협업 기록 3요소 (T02-C31)
1. **AI에게 맡긴 일**: HTML5 Canvas 기반 2D 러너 물리 엔진(중력, 충돌 박스 판정), Web Audio API 오디오 합성 코드 생성, PC 경계 검사 템플릿 작성
2. **학생이 직접 판단한 일**: 미국 서부 건슬링어 테마 선정, 30초 완주 성공 규칙 및 Speed 7 난이도 수치 결정, 검정/갈색/흰색 서부 무드 색채 기획
3. **AI 제안을 따르지 않은 일**: AI가 초기에 제안한 복잡한 3D 그래픽 엔진(Three.js)을 기각하고, 0.05초 즉시 구동과 10분 연속 실행 안정성을 위해 순수 경량 Canvas 코드로 제작하도록 통제함.
