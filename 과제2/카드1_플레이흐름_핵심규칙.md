# [과제 2 / 카드 1] 30초 핵심 규칙

## 남길 것: 한 판의 시작·진행·종료·재시작

### 1. 공개 화면 및 상태 표시 (T02-C03, T02-C04, T02-C05)
- 게임 규칙, 핵심 조작(Space/점프, P/일시정지, R/재시작), 현재 점수, 30초 카운트다운 타이머가 화면 상단에 상시 노출됨.
- 무로그인 공개 실행: [https://skt-aleph-gilt.vercel.app/game.html](https://skt-aleph-gilt.vercel.app/game.html)

---

### 2. 조작과 물리 상태 변화 (T02-C06)
- 점프 조작(Space 키, 방향키 위, 화면 터치/클릭) 1회 입력 시 캐릭터의 상승 가속도 및 물리 점프 상태 1회 정확 반영.
- 다중 연속 입력 시에도 바닥 착지 전 중복 누적 점프 방지(1회만 유효 처리).

---

### 3. 30초 핵심 루프 흐름 (T02-C07)
1. **시작 (Start)**: `[게임 시작]` 버튼 클릭 또는 Space 키 입력
2. **진행 (Running)**: 30초 동안 서부 황야를 달리며 선인장, 회전초 장애물 회피 (생존 시간 비례 초당 점수 획득)
3. **완주 성공 (Success)**: 30초 생존 완료 시 '보안관 배지 획득(SHERIFF SUCCESS)' 달성
4. **실패 종료 (Game Over)**: 장애물 접촉 판정 시 즉시 '현상수배(WANTED GAME OVER)' 상태 전환

---

### 4. 재시작 검증 (T02-C08, T02-C09)
- 성공 후 재시작: 시간(30초), 점수(0점), 플레이어 위치, 장애물 스폰 큐가 완전 초기화됨.
- 실패 후 재시작: 시간(30초), 점수(0점), 플레이어 위치, 장애물 스폰 큐가 완전 초기화됨.
