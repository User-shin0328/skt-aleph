## 3. 할 일 조작 및 기능 실증

1. **할 일 생성 (Create)**:
   - [새 할 일 추가] 버튼을 눌러 모달에서 제목, 마감일, 우선순위, 태그, 예상 시간을 입력하여 즉시 목록 및 서버 DB에 추가됨.
2. **할 일 내용 수정 (Update)**:
   - 각 카드의 [✏️] 버튼으로 모달을 열어 마감일이나 예상 시간을 수정할 수 있으며 실시간 반영됨.
3. **완료 상태 전환 및 되돌리기 (Toggle)**:
   - 체크박스 클릭 시 `completed` 상태로 전환되며 완료 취소선이 표시됨.
   - 이미 완료된 할 일의 체크박스를 다시 누르면 `pending` 상태로 복귀하고 취소선이 해제됨.
4. **할 일 삭제 (Delete)**:
   - [🗑️] 버튼 클릭 시 확인 후 해당 할 일과 연결된 실행 기록이 함께 깔끔히 제거됨.
5. **실시간 검색 (Search)**:
   - 상단 검색창에 키워드 입력 시 제목, 태그, 막힌 사유를 대상으로 즉각적인 필터링 수행.
6. **조건 거르기 (Filter)**:
   - [전체], [진행 중], [완료됨], [지연됨], [막힘 발생] 버튼으로 상태별 즉각 분기 렌더링.
7. **정렬 기준 화면 명시 (Sort)**:
   - 화면에 다음 기준이 명확히 고지됨:
     `* 화면 정렬 기준: 마감일 빠른 순 (오름차순, 동일 마감일 시 등록 역순 우선)`
   - 셀렉트 박스에서 마감일 늦은 순, 우선순위 높은 순, 예상 시간 긴 순, 최근 등록 순으로 즉시 재정렬 지원.\n
