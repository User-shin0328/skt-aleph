# [과제 1 / 카드 5] 내 손으로 완성

## 남길 것: 상호작용·움직임 선택·비밀값 점검 & 제출 확인문

---

### 1. 접근 가능한 상호작용 (T01-C19 ~ T01-C21)
- **근거 열람 모달 팝업**:
  * 마우스 클릭으로 열기/닫기 정상 동작 (T01-C20)
  * Tab 키 포커스 진입 후 Enter / Space 및 ESC 키보드 조작 완벽 지원 (T01-C21)
- **실시간 방명록 (Supabase 연동)**:
  * 마우스 및 키보드로 닉네임/메시지 입력 후 등록 완료

---

### 2. 움직임 선택권 (T01-C22)
- 상단 헤더에 **[움직임 줄이기 (Reduce Motion)]** 토글 스위치 제공
- 클릭 시 CSS 트랜지션 및 화면 효과를 즉각 비활성화하여 전정신경 질환자 및 사용자 선택권 보장

---

### 3. 보안 및 비밀값 점검 (T01-C23, T01-C24)
- 비공개 개인정보 노출: **0건**
- 비밀번호, 비공개 토큰, API 마스터 시크릿 키 원문 노출: **0건** (Supabase 공개 Anon Key만 안전 배포)

---

### 4. 짧은 확인 방법 4단계 (T01-C25)
1. **어디로 가나요**: 공개 주소 [https://skt-aleph-gilt.vercel.app/](https://skt-aleph-gilt.vercel.app/) 에 시크릿 창으로 접속합니다.
2. **3단계 이내 무엇을 하나요**:
   - Step 1: [근거 열람] 버튼을 클릭하거나 Tab+Enter로 엽니다.
   - Step 2: 방명록에 메시지를 입력하고 등록 버튼을 누릅니다.
   - Step 3: 상단 [움직임] 토글 버튼을 클릭하여 애니메이션을 끕니다.
3. **무엇이 보이면 통과인가요**: 근거 팝업이 뜨고, 방명록 피드에 새 글이 추가되며, 화면의 전환 효과가 즉각 멈추면 통과입니다.
4. **안 될 때 무엇이 보이나요**: 키보드 포커스 링이 보이지 않거나 팝업이 열리지 않고 콘솔에 붉은 에러가 발생하는 경우입니다.

---

### 5. AI 협업 기록 3요소 (T01-C26)
1. **AI에게 맡긴 일**: HTML/Tailwind CSS 기본 마크업 구조 생성, WCAG 명암비 계산 검증, Supabase JS 통신 연동 코드 바인딩
2. **학생이 직접 판단한 일**: RM.txt 기반 3대 핵심 역량의 실제 경험 정립, 시스템 관점의 공개/보호 범위 분리 결정, 검정·갈색·흰색·회색 모노톤 색채 조합 결정
3. **AI 제안을 따르지 않은 일**: AI가 초기에 제안한 원색 네온 컬러와 평가용 메타 텍스트(카드 1~5, 배점 기준)의 본문 노출을 전면 배제하고, 자연스러운 엔지니어링 포트폴리오로 재작성하도록 통제함.
