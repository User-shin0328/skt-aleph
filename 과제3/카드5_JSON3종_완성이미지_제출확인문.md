### 3. 짧은 확인 방법 4단계 (T03-C31)
1. **어디로 가나요**: [https://skt-aleph-gilt.vercel.app/studio](https://skt-aleph-gilt.vercel.app/studio)
2. **3단계 이내 무엇을 하나요**:
   - Step 1: 화면비 버튼(1:1, 4:5, 9:16)을 선택하고 문구를 수정합니다.
   - Step 2: 템플릿 관리 패널에서 [+ 현재 저장]을 눌러 템플릿을 생성합니다.
   - Step 3: [⬇ PNG 고해상도 다운로드]를 클릭하여 파일을 저장하고 미리보기와 대조합니다.
3. **무엇이 보이면 통과인가요**: 캔버스에 문구와 비율이 실시간 반영되고, 생성한 템플릿이 새로고침 후에도 유지되며, 다운로드된 파일의 문구 줄바꿈과 배치가 화면과 완전히 일치하면 통과입니다.
4. **안 될 때 무엇이 보이나요**: 지원하지 않는 파일 업로드 시 붉은 경고 배너 없이 멈추거나, 다운로드된 파일의 글자 위치가 잘리거나, 콘솔에 빨간 오류가 출력되는 상태입니다.

1. **AI에게 맡긴 일**: Canvas 텍스트 자동 줄바꿈 알고리즘 구현, 단어/음절 오버플로우 방지 스케일링 수식 작성, JSON 유효성 검증 파서 템플릿 코드 생성

3. **AI 제안을 따르지 않은 일**: 외부 대용량 그래픽 라이브러리(Fabric.js 등)를 배제하고 무거운 종속성 없이 즉각적인 반응성을 위해 순수 HTML5 Canvas 2D 컨텍스트로 직접 구현함.
