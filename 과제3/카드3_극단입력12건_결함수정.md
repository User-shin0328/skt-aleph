# [과제 3 / 카드 3] 열두 가지 입력

## 남길 것: 12개 검사표와 대표 결함 전후

---

### ■ 대표 결함 수정 내역 (T03-C15)
- **결함 현상**: 50자 이상의 긴 한글 문장이나 띄어쓰기 없는 긴 영단어 입력 시 캔버스 좌우 경계를 벗어나 끝부분이 잘려나감.
- **수정 전 (FAIL)**: Canvas 기본 `fillText()`는 자동 줄바꿈을 지원하지 않아 텍스트 절단 결함 발생.
- **수정 후 (PASS)**: 단어 단위 및 음절/글자 단위 강제 래핑 지능형 함수(`wrapText()`)를 구현하고, 세로 높이 초과 시 폰트 크기를 단계적으로 자동 축소(Scale-down)하는 안전 루프를 적용하여 잘림 현상 0건 달성.
