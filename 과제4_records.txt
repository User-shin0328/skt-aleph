[카드 3 남길 것] 다섯 가지 실패 (실패 상태와 마지막 정상값 보존, 오래된 값 표시 및 복구)
--------------------------------------------------------------------------------
1. 외부 원천 실패 5종 대응 아키텍처:
   - ① 느린 응답 (Timeout / Slow): 네트워크 지연 발생 시 직전 정상 캐시값 유지
   - ② 외부 원천 401/403 거절 (Unauthorized / Forbidden): HTTP 오류 포착 후 마지막 정상값 보존 배너 작동
   - ③ 외부 원천 호출 제한 (Rate Limit 429): 일시적 호출 한도 초과 시 기존 화면값 유지
   - ④ 오프라인 상태 (Offline / Network Error): 인터넷 단절 시 localStorage에 저장된 직전 정상값으로 즉시 복원
   - ⑤ 응답 형식 변경 (Schema Drift / Mismatch): 필수 키 누락 시 파싱 유효성 검사에서 차단하고 이전 정상값 보존
2. 마지막 정상값 보존 및 오래된 값 경고 배너 (T04-C17, T04-C18):
   - 통신 오류 발생 시 기존에 표시되던 기온 및 환율 데이터가 화면에서 지워지거나 '--'로 초기화되지 않고 안전하게 보존됨.
   - 화면 상단에 붉은색/노란색 경고 배너(#liveStaleBanner) 자동 출력:
     * "⚠️ 외부 원천 장애 — 마지막 정상값 보존 중 (최신 데이터를 가져오지 못하여 직전 정상 조회값을 표시합니다)"
3. 다시 시도 및 정상 상태 복구 (T04-C19):
