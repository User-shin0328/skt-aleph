# [과제 4 / 카드 3] 다섯 가지 실패

## 남길 것: 실패 상태와 마지막 정상값 보존, 오래된 값 표시 및 복구

---

### 1. 외부 원천 실패 5종 대응 아키텍처

| 장애 유형 | 원인 시나리오 | 시스템 대응 및 보존 동작 |
|:---|:---|:---|
| **① 느린 응답** | 네트워크 지연 및 Timeout | 기존 화면 기온/환율 유지 및 타임아웃 방어 |
| **② 401/403 거절** | 외부 원천 인증/권한 에러 | 에러 포착 후 직전 정상값 보존 배너 작동 |
| **③ 호출 제한 (429)** | Rate Limit 초과 | 일시적 제한 시 기존 저장된 정상 데이터 유지 |
| **④ 오프라인** | 인터넷 연결 단절 | localStorage에 저장된 직전 정상값으로 즉시 복원 |
| **⑤ 응답 형식 변경** | 필수 스키마 키 누락/변형 | 파싱 유효성 검사 차단 및 이전 정상값 안전 보존 |

### 2. 마지막 정상값 보존 및 오래된 값 경고 배너 (T04-C17, T04-C18)
- 통신 오류 발생 시 기존에 표시되던 기온 및 환율 데이터가 화면에서 지워지거나 초기화되지 않고 안전하게 보존됨.
- 화면 상단에 경고 배너(`liveStaleBanner`) 자동 노출:
  > **"⚠️ 외부 원천 장애 — 마지막 정상값 보존 중 (최신 데이터를 가져오지 못하여 직전 정상 조회값을 표시합니다)"**

---

### 3. 다시 시도 및 정상 상태 복구 (T04-C19)
- 배너 내 `[다시 시도]` 버튼 또는 `[실제 데이터 지금 조회하기]` 클릭 시 재조회 수행.
- 외부 API 정상 응답 수신 시 경고 배너가 즉시 사라지고 최신 관측값으로 자동 정상화 완료.
