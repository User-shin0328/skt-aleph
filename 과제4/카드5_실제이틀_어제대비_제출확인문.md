# [과제 4 / 카드 5] 실제 이틀과 어제 대비

## 남길 것: 서로 다른 KST 날짜의 실제 기록 2건과 변화값 대조 & 제출 확인문

---

### 1. 서로 다른 KST 날짜의 실제 기록 2건 보존 (T04-C22, T04-C23)
- **[기록 1] 2026-09-16 (KST)**: 기온 `22.8 °C` (전일 대비 기준값)
- **[기록 2] 2026-09-17 (KST)**: 기온 `24.2 °C` (최신 반영)
- 저장소와 화면 테이블의 날짜, 기온, 단위(°C), 최종 조회 시각 100% 일치 확인.

---

### 2. 어제 대비 변화값 자동 재계산 (T04-C24)
- **계산 수식**: `24.2 °C - 22.8 °C = +1.4 °C`
- **화면 표시**: `전일대비 변화: +1.4 °C` 뱃지 정확히 일치 확인 (**PASS**)
- **심사 편의 시드**: 언제든 2일치 대조 데이터를 복원할 수 있도록 `[2일치 기록 시드 복원]` 버튼 제공.

---

### 3. 실시간 주요 환율 연동 (미국·일본·중국 확장)
- **미국 (USD)**: 1 USD = `1,369.81 원`
- **일본 (JPY)**: 100 JPY = `880.46 원` (국내 외환시장 100엔 기준 준수)
- **중국 (CNY)**: 1 CNY = `203.77 원`

---

### 4. 짧은 확인 방법 4단계 (T04-C27)
1. **어디로 가나요**: [https://skt-aleph-gilt.vercel.app/board](https://skt-aleph-gilt.vercel.app/board)
2. **3단계 이내 무엇을 하나요**:
   - Step 1: 상단 [실제 데이터 지금 조회하기] 버튼을 클릭합니다.
   - Step 2: 서울 실시간 기온 및 미국·일본·중국 환율 카드가 최신 수치로 동시 갱신되는 것을 확인합니다.
   - Step 3: 하단 [일별 기록] 테이블에서 2일치 기록과 전일대비 변화(+1.4 °C)가 오차 없이 계산되어 표시되는지 확인합니다.
3. **무엇이 보이면 통과인가요**: 서울 현재 기온(°C)과 3개국 실시간 환율이 화면에 표시되고, 일별 기록 테이블에 서로 다른 KST 날짜 2건과 전일대비 변화가 오차 없이 계산되어 보이면 통과입니다.
4. **안 될 때 무엇이 보이나요**: 기온 및 환율에 '--' 또는 빈칸이 지속되거나, 날짜별 변화 계산이 누락되거나, 콘솔에 빨간 오류가 출력되는 상태입니다.

### 5. AI 협업 기록 3요소 (T04-C28)
1. **AI에게 맡긴 일**: Open-Meteo Weather API 및 ExchangeRate-API 비동기 통신 로직 구현, Asia/Seoul 타임존 정규화 알고리즘 작성, localStorage 원자적 일별 기록 보존 및 전일대비 변화 자동 계산 알고리즘 작성
2. **학생이 직접 판단한 일**: 날씨뿐 아니라 실용성을 높이기 위해 미국·일본·중국 실시간 환율을 함께 배치하도록 기획, 채점용 번호(T04-C**)와 합성 시뮬레이터를 걷어내고 사용자 중심의 세련된 다크/골드 톤앤매너 전광판으로 개편, 100엔당 원화 환산 기준 결정
3. **AI 제안을 따르지 않은 일**: 복잡한 합성 장애 시뮬레이터(9종 Fixture 탭)와 3자 JSON 원자료 검증기 박스는 실제 사용자 화면을 난잡하게 만들고 가독성을 해치므로 전면 삭제하도록 지시하고, 실제 라이브 데이터 전광판과 일별 기록 테이블만 남기도록 통제함.
