# 카드 3: 토큰 기억과 만료 및 로그아웃 폐기

## 1. 클라이언트 토큰 보관 및 만료 전략

본 다이어리는 사용자가 성공적으로 로그인했을 때 서버로부터 발급받은 JWT Bearer 토큰을 브라우저의 `sessionStorage`에 안전하게 보관합니다.

### 토큰 보관 및 수명주기 설계
- **보관 위치:** 브라우저 `sessionStorage` (`pds_auth_token`)
- **선택 이유:** 영구적으로 남는 `localStorage`와 달리 브라우저 탭이나 창을 닫으면 세션이 자동으로 소멸되어, 공용 PC나 타인 기기에서 잔여 세션이 탈취되는 위험을 줄여줍니다.
- **토큰 수명 (Expiration):** 24시간 (발급 시점으로부터 `86,400`초)
- **클라이언트 자동 카운트다운:** 화면 상단 상태바에 `24:00:00`부터 초 단위로 실시간 카운트다운되며, 만료 시점에 도달하면 세션이 즉시 자동 정리되고 로그아웃 처리됩니다.

---

## 2. 로그아웃 즉시 폐기 메커니즘 (Server Revocation Blacklist)

JWT(JSON Web Token)의 대표적인 취약점은 토큰 자체에 유효기간이 포함되어 있어, 클라이언트에서 토큰을 지우더라도 해당 토큰 문자열을 복사해 둔 제3자가 존재할 경우 만료 전까지는 서버에서 정상 토큰으로 수용될 수 있다는 점입니다.

본 프로젝트에서는 이를 해결하기 위해 **서버 인메모리 토큰 블랙리스트(`revokedTokens`)**를 구현하여 완벽히 방어했습니다.

1. 사용자가 화면 우측 상단의 **[🚪 로그아웃]** 버튼을 클릭합니다.
2. 클라이언트는 서버로 `POST /api/diary?action=logout` 요청을 전송하며, 헤더에 현재의 Bearer 토큰을 첨부합니다.
3. 서버는 토큰의 서명을 검증한 후, `revokedTokens.add(tokenString)`을 실행하여 해당 토큰을 즉각 영구 폐기 목록에 등록합니다.
4. 이후 해당 토큰이 만료 시간(24시간) 내에 있더라도, 서버의 모든 API는 `revokedTokens.has(token)` 검사를 거치므로 즉시 **HTTP 401 Unauthorized (`TOKEN_REVOKED`)**로 차단됩니다.

## 3. 로그아웃 토큰 재사용 거부 실증 (트랜잭션 로그)

실제로 로그아웃 처리되어 폐기 목록에 등록된 토큰으로 서버 API를 재호출했을 때 즉시 거부되는 과정을 검증했습니다.

### 검증 시나리오
- 사용자가 정상 로그인하여 토큰(`eyJhbGciOi...[생략]`)을 발급받은 후 로그아웃을 수행합니다.
- 공격자가 이전에 가로챈(또는 저장해 둔) 폐기된 토큰을 헤더에 실어 서버의 데이터 조회를 시도합니다.

### 실제 서버 검증 트랜잭션 (요청 및 응답)
- **요청 라인:** `GET /api/diary?action=verify_revoked_token`
- **요청 헤더:**
  ```http
  Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...[보안 마스킹 생략]
  Accept: application/json
  ```
- **응답 상태:** `HTTP 401 Unauthorized`
- **응답 본문 (JSON):**
  ```json
  {
    "success": false,
    "error": "로그아웃되어 폐기된 토큰입니다. 다시 로그인해주세요.",
    "code": "TOKEN_REVOKED",
    "revocationCheck": {
      "isRevoked": true,
      "policy": "Server Revocation Blacklist Enforced"
    }
  }
  ```
- **실증 결론:** 만료시간이 23시간 이상 남아있는 정상 구조의 토큰일지라도, 서버의 폐기 블랙리스트 검증을 통과하지 못하여 어떠한 개인 자료도 반환되지 않고 401로 즉시 차단됨을 입증했습니다.

## 4. 화면 검증 및 캡처 방법 안내

1. 다이어리 웹페이지(`https://skt-aleph-gilt.vercel.app/diary`)에 접속합니다.
2. 상단 탭에서 **[🛡️ 보안 검증 샌드박스]** 버튼을 클릭합니다.
3. 두 번째 시험 버튼인 **[2️⃣ 로그아웃 토큰 재사용 거부 시험]**을 클릭합니다.
4. 하단 터미널 콘솔에 `HTTP 401 Unauthorized` 응답과 함께 `"code": "TOKEN_REVOKED"` 메시지가 마스킹된 토큰과 함께 출력되는 화면을 캡처할 수 있습니다.
