# 카드 5: 6대 인증 설명서 및 5일 연속 러닝 기록

## 1. 인증 구현 설명서 (6대 핵심 기준)

### ① 무엇을 골랐는가
- **비밀번호 단방향 솔트 해싱:** `PBKDF2-HMAC-SHA256` (100,000회 스트레칭, 계정별 고유 32바이트 암호학적 랜덤 Salt 생성 결합).
- **사용자 세션 토큰:** 무상태(Stateless) 기반 `JWT (JSON Web Token)` — 서명 알고리즘 `HMAC-SHA256`, 24시간 타임아웃, `Authorization: Bearer` 헤더 통신.
- **토큰 폐기 메커니즘:** 서버 인메모리 블랙리스트 세트(`revokedTokens`)를 통한 로그아웃 즉시 폐기.

### ② 왜 골랐는가
- **Vercel Serverless 무상태성 유지:** 분산 서버리스 런타임에서 별도의 세션 DB 클러스터 없이도 전자서명 검증을 통해 신속하고 안정적인 인가가 가능합니다.
- **외부 종속성 배제:** Node.js 표준 `crypto` 모듈만을 사용하여 npm 모듈 설치나 공급망 취약점 위험을 원천 차단했습니다.
- **GPU 사전 공격 저항성:** 10만 회 해시 반복을 통해 레인보우 테이블과 오프라인 브루트포스 연산 비용을 극대화하여 무력화했습니다.

### ③ 소스의 어디를 고쳤는가
- **`contracts/pds-schema-v2.json`:** v2.1.0 스키마로 승격하여 `users`, `authRules`, `five_day_running_records` 계약 추가.
- **`api/diary.js`:** L40~L180(암호화/토큰/블랙리스트 함수), L220~L380(인증 액션 및 IDOR 소유권 대조 인가 검증 미들웨어).
- **`diary.html`:** 미로그인 시 개인 자료를 격리하는 Auth Gate, 24시간 세션 카운트다운 타이머, 5일간 러닝 데이터 렌더링 및 보안 검증 샌드박스.

### ④ 무엇을 직접 확인했는가
- **동일 비밀번호 상이 해시 검증:** 같은 비밀번호(`P@ssw0rd123!`)를 사용하는 두 계정이 서로 다른 Salt와 Hash를 생성함을 실시간 확인.
- **로그아웃 토큰 재사용 차단 검증:** 로그아웃으로 폐기된 토큰으로 재요청 시 `HTTP 401 Unauthorized (TOKEN_REVOKED)`로 즉각 차단됨을 확인.
- **IDOR 타인 리소스 침범 차단 검증:** `runner_guest` 토큰으로 `runner_shin` 자료 수정 시도 시 `HTTP 403 Forbidden` 차단 및 데이터 변경 0건 확인.
- **무인증 직접 호출 차단 검증:** 토큰 미포함 요청 시 `HTTP 401 Unauthorized` 거부 확인.

### ⑤ 아직 못 막은 것은 무엇인가
- **동일 IP 기반 무차별 대입 공격(Brute-force) 제한 부재:** 로그인 실패 시 초당 시도 횟수를 강제 제한하는 전역 Rate Limiter가 적용되지 않아 분산 사전 공격에 노출될 잠재적 위험이 있습니다.
- **브라우저 스토리지 XSS 토큰 탈취 위험:** 현재 클라이언트 토큰이 `sessionStorage`에 보관되어 웹 스크립트 인젝션(XSS) 취약점 발생 시 토큰이 탈취될 수 있습니다.

### ⑥ 앞으로 어떻게 보완할 것인가
- **Redis (Upstash) 기반 전역 Rate Limiting 구축:** 동일 IP/계정당 1분간 최대 5회 로그인 실패 시 15분간 요청을 자동 차단하는 분산 잠금 시스템 도입.
- **HttpOnly Secure SameSite 쿠키 & Refresh Token 전환:** 액세스 토큰은 자바스크립트 메모리에만 유지하고 리프레시 토큰은 HttpOnly 쿠키로 격리하여 XSS 토큰 탈취 위협을 원천 봉쇄.

## 3. 수동 계산 거리 합산 및 가중 평균 페이스 검증

1. **5일간 총 달린 거리 수동 합산:**
   $$8.0 + 8.5 + 9.0 + 8.5 + 9.5 = 43.5\text{ km}$$
2. **5일간 총 소요 시간 합산:**
   $$42 + 44 + 46 + 44 + 49 = 225\text{ 분 (3시간 45분)}$$
3. **가중 평균 페이스 계산식:**
   $$\text{가중 평균 페이스} = \frac{\sum(\text{거리}_i \times \text{페이스}_i)}{\text{총 거리}} = \frac{8.0 \times 315 + 8.5 \times 310 + 9.0 \times 305 + 8.5 \times 312 + 9.5 \times 308}{43.5}$$
