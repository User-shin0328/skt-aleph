# 계속 새로 쓰는 장치 (Site & Profile Data Generator)

본 장치는 리추얼 기록(`ritual.txt`), 과제 제출 목록(`submissions.txt`), 출석 숫자(`attendance.txt`) 파일을 입력받아, 13주 통계 숫자와 세 능력(자기조절력, 대인관계력, 자기동기력)별 문단 후보를 날짜 및 근거와 함께 자동으로 집계·추출해 주는 자동화 프로그램입니다.

본 장치는 과정이 끝난 뒤에도 새 기록을 넣고 실행하면 사이트가 언제나 최신 상태로 유지되도록 돕습니다. 또한 동일한 입력에 대해 언제나 100% 동일한 결과를 보장하는 결정론적(Deterministic) 멱등성을 갖추고 있습니다.

---

## 🚀 돌리는 방법 3단계 (Quick Start)

### [Step 1] 입력 데이터 확인 및 준비
- `data/` 디렉터리 내에 3개의 입력 데이터 파일이 위치하는지 확인합니다:
  - `data/attendance.txt`: 출석 일수 및 손목 부상 출결 기록
  - `data/submissions.txt`: 11개 과제 제출 및 검증 통과 이력
  - `data/ritual.txt`: 29일간의 데일리 리추얼 및 강점 실천 일화

### [Step 2] 장치 실행 (데이터 집계 및 문단 후보 생성)
- 터미널을 열고 본 `device/` 폴더에서 아래 파이썬 명령어를 실행합니다:
  ```powershell
  python generate.py
  ```
- 실행 시 화면에 SHA-256 검증 해시와 집계 요약(출석률 100%, 리추얼 29일, 완주율 100%)이 출력됩니다.

### [Step 3] 결과 확인 및 사이트 반영
- `output/` 폴더에 생성된 산출물을 확인합니다:
  - `output/candidates.md`: 날짜와 근거가 붙은 세 능력별 문단 후보 명세표
  - `output/candidates.json`: 구조화된 후보 데이터 원본
  - `output/site_data.json`: 웹사이트용 최종 집계 데이터
  - `output/site_data.js`: 브라우저 즉시 바인딩용 스크립트
  - `output/run_summary.json`: 실행 상태 및 무결점 해시 요약
- 내가 승인(`approved: true`)한 후보와 최신 숫자가 웹 포트폴리오 사이트에 즉시 반영됩니다.

## 🔒 보안 및 비공개 원칙 (BRA-C10 준수)
- 본 장치 소스코드 및 입출력 데이터 어디에도 타인의 실명, 전화번호, 개인 메타데이터가 일체 포함되어 있지 않습니다.
- 데이터베이스 비밀키, 관리자 토큰, API 키 등 모든 비밀값(Secrets)이 0건으로 안전하게 격리되어 있습니다.
