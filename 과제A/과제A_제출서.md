## 3. 짧은 확인 방법 (4단계 재현 가이드) (BRA-C11 충족)

1. **사이트 주소 및 위치**:
   - 공개 사이트: `https://skt-aleph-gilt.vercel.app/portfolio`
   - **상단 메뉴 바**: 상단 GNB를 통해 5개 핵심 페이지(`내 이야기`, `13주 실증 기록`, `대표작`, `입사 지원 문서`, `설정`)를 즉시 이동할 수 있습니다.
   - **첫 화면 (Above-the-fold)**: 상단에 본인 이름 "신재원"과 한 줄 소개 *"비바람의 계절을 건너며 단단해진 회복탄력성으로 묵묵히 제자리를 지켜내는 사람"* 및 공개 이메일이 위치합니다.
   - **내 이야기 위치 (`/portfolio.html`)**: 첫 화면 바로 아래 단일 카드 섹터에 1,549자 본편(고난, 다시 일어난 날, 대전 부트캠프, 대인관계력, 자기동기력, 자기조절력, 포부)이 하나의 흐름으로 배치되어 있습니다.
   - **숫자 칸 위치 (`/records.html`)**: 13주 출석률(100%, 9/4 손목 통증 극복 일화 짝지음), 데일리 리추얼(29일 100%), 과제 제출 완주율(11/11개 100%)과 각 출처 및 상위 3대 강점 총괄 대조표가 명시되어 있습니다.
   - **대표작 위치 (`/projects.html`)**: 10번 논문(외계행성 분류 머신러닝 논문, 즉시 열람)과 13번 앱 예정 자리(제로트러스트 보안 웹 앱, 2026-10-16 예정일)가 위치합니다.
   - **문서 위치 (`/documents.html`)**: 이력서, 자기소개서, STAR 경력기술서 탭 뷰어 및 ZIP 패키지 다운로드 링크가 위치합니다.
   - **설정 위치 (`/updater.html`)**: 새 기록을 넣으면 사이트의 숫자와 문단 후보를 다시 계산해 주는 지속 갱신 인터랙티브 엔진 및 CLI 실행 가이드가 위치합니다.

2. **문서와 장치 ZIP 안 어디에 무엇이 있나요**:
   - 파일 경로: `과제A/과제A_신재원_패키지.zip` (비밀번호 없음)
   - ZIP 내부 구조:
     - `문서/이력서_신재원.md`: OCS 해군 장교 복무, 자격증 3종, 13주 엔지니어링 집중 훈련 명세
     - `문서/자기소개서_신재원.md`: 1,479자 정본 자기소개서 (고난 -> 결단 -> 세 능력 발현)
     - `문서/경력기술서_신재원.md`: 과제 1~11 전체 과제별 세 능력 매핑 및 1줄 STAR 요약
     - `device/generate.py`: 리추얼/과제/출석 데이터를 파싱하여 숫자와 문단 후보를 생성하는 파이썬 스크립트
     - `device/README.md`: 3단계 실행 가이드
     - `device/data/`: `attendance.txt`, `ritual.txt`, `submissions.txt` (입력 데이터)
     - `device/output/`: `candidates.md`, `candidates.json`, `site_data.json`, `site_data.js`, `run_summary.json` (마지막 실행 결과)

3. **세 단계 안에 어떤 명령이나 확인을 하나요**:
   - **Step 1**: 터미널에서 `과제A/device` 폴더로 이동합니다.
   - **Step 2**: 자동 생성 장치를 실행합니다:
     ```powershell
     python generate.py
     ```
   - **Step 3**: 출력 창에서 SHA-256 무결점 검증 해시와 통계 집계 결과를 확인합니다:
     - 출력: `[장치 실행 완료] SHA-256: d53b94d879f2ba528de8c6eeb2f2b62ba7596e1c93cf2d5840169eb3df76f721`
     - 출력: `출석률: 100.0%, 리추얼: 29일, 제출완료: 100.0%`
     - 출력: `승인된 문단 후보: 3건`

4. **무엇이 나오면 통과이고 안 될 때는 무엇이 나오나요**:
   - **통과**: 임시 폴더에서 2회 연속 실행 시 SHA-256 해시가 완벽히 동일하고, diff 비교 시 차이점 0건이 확인되면 통과입니다.
   - **실패**: 데이터 누락으로 에러가 발생하거나 해시가 불일치할 경우 즉시 실패 판정이 내려집니다.

## 4. AI와 나의 판단 세 줄 (BRA-C12 충족)

1. **AI에게 맡긴 일**:  
   - 모바일과 데스크톱 전 해상도에서 쾌적하게 3분 안에 읽히는 반응형 포트폴리오 웹 UI 퍼블리싱 및 3개 입력 데이터(`attendance.txt`, `ritual.txt`, `submissions.txt`)를 정밀 파싱하여 결정론적 JSON/JS로 정규화하는 `generate.py` 알고리즘 코드를 작성한 일.

2. **내가 직접 판단한 일**:  
   - 2022~2024년 대구 상가 자영업 실패와 은둔이라는 쓰라린 고난을 솔직하게 마주하고, 2025년 말 대전으로 이동하여 정보보안으로 전향한 실제 삶의 궤적을 1,479자 진솔한 자기소개 본편으로 정제하였으며, 13주 출석률 100%라는 숫자를 9월 4일 손목 통증 투혼 출석 일화와 일대일로 짝지어 실증한 일.

3. **AI 제안을 따르지 않은 일 (이유)**:  
   - AI가 초기에 제안했던 화려한 미사여구, 복잡한 페이드인 애니메이션, 로그인 모달 창 기능을 단호히 배제함. 처음 온 면접관이나 동료가 3분 안에 로그인이나 지연 없이 신뢰감과 기술적 실증을 즉시 확인할 수 있도록, 간결하고 정직한 웹 표준 레이아웃과 100% 공개 접근성을 일관되게 고수함.
