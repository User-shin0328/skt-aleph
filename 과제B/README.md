# ExoForge: 골디락스를 찾아서 (ExoForge: Hunt for Goldilocks)
> **과제 B 대표작 웹 애플리케이션**  
> **기반 학술 논문**: *"별에 철이 많으면 행성도 더 커질까? - NASA의 2,220개 외계행성 데이터로 밝혀낸 거대 행성의 탄생 비밀"* (신재원 저)

---

## 1. 이 앱이 누구를 어떻게 돕는가 (한 문장 규격)
> **"천체물리학과 우주과학에 관심 있는 청소년 및 입문자가 외계행성의 탄생 환경을 탐구할 때, 이 앱이 NASA 2,220개 실제 관측 데이터와 핵 강착 모델을 바탕으로 모항성의 철 함량([Fe/H])이 거대 가스행성과 골디락스 행성의 형성에 미치는 영향을 시뮬레이션과 인터랙티브 차트로 즉시 검증하고 체험할 수 있도록 돕는다."**

---

## 2. 사용자가 할 일 세 가지 (Three User Tasks)

1. **항성계 제작 시뮬레이터 조작 (Stellar Forge)**
   - 모항성의 철(금속) 함량 슬라이더(`[Fe/H]`: -0.50 ~ +0.50 dex)를 조절하고 `[항성계 생성 (FORGE)]` 버튼을 클릭합니다.
   - 60fps 케플러 궤도 공전 애니메이션, 골디락스 존(녹색 네온 링), 그리고 생성된 행성 중 제2의 지구 적합도 점수(0~100점) 리포트를 실시간으로 확인합니다.

2. **NASA 실제 관측 데이터 2,220개 산점도 탐색 (ExoData Explorer)**
   - Chart.js 기반 산점도에서 행성 유형 필터(지구형, 슈퍼지구, 해왕성형, 가스거인) 및 골디락스 존 필터를 적용합니다.
   - Y축 스케일(로그/선형)을 토글하고, 개별 데이터 포인트를 클릭하여 외계행성의 실제 물리 제원과 10번 논문의 핵심 이론 해설을 비교 분석합니다.

3. **우주 탐정 자격 퀴즈 풀이 및 연구원 승급 (Detective Quiz)**
   - 10번 논문의 핵 강착(Core Accretion) 원리와 골디락스 존 형성 원리를 다룬 5단계 객관식 퀴즈를 풀고 정답/오답 해설을 확인합니다.
   - 최종 획득 점수에 따라 'NASA 명예 연구원 인증 카드(수습 관측원 &rarr; 외계행성 분석가 &rarr; 수석 천체물리학자)'를 발급받아 PNG 이미지로 다운로드하거나 연구 결과를 클립보드로 공유합니다.

---

## 3. 오프라인 및 로컬 실행 방법 (새 임시 폴더에서 즉시 실행)

본 애플리케이션은 별도의 빌드 과정, 백엔드 서버 구동, 패키지 설치(`npm install` 등)가 일절 필요 없는 **단일 파일(Self-contained HTML)** 구조로 설계되었습니다.

### 실행 절차 (3초 완성)
1. 압축을 푼 폴더 내 `index.html` (또는 프로젝트 루트의 `exoforge.html`) 파일을 찾습니다.
2. 크롬, 엣지, 사파리, 웨일 등 임의의 최신 웹 브라우저에서 **더블클릭**하여 엽니다.
3. 로그인, 회원가입, API 키 입력 없이 즉시 모든 기능(시뮬레이터, 산점도, 퀴즈, 인증서 발급)이 100% 정상 작동합니다.
