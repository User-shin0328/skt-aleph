과제 13 대표작 2026-10-16 출시 예정

13번 제로트러스트 보안 웹 애플리케이션

클라우드 네이티브 제로트러스트(Zero Trust) 환경에서 W3C WebAuthn 레벨 3 생체인증과 엔드투엔드 PBKDF2 암호화 엔진을 결합하여, 실시간 데이터 무결성을 검증하고 감사 로그를 보존하는 차세대 보안 웹 애플리케이션입니다.

예정 스택: WebAuthn · Web Crypto API · Zero-Trust
과제 진행: 대표작 자리 사전 구축 완료 (과제 13 완료 후 채움)
